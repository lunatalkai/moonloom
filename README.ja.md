# Moonloom

**[繁體中文](README.md) · [English](README.en.md) · 日本語 · [한국어](README.ko.md)**

Moonloom は LunaTalk の創作ツールキットです。ふだん使っている AI アシスタントに
入れると、そのアシスタントが LunaTalk 実際のルールに沿って、ロールカードの構想・
修正・実地テスト・審査提出まで一緒に進めてくれます。

決めるのはあなた。下書きと確認と面倒な作業はアシスタントの担当です。

## はじめる前に

- LunaTalk のアカウント。カードはあなたのアカウントの下に作られ、提出するまで
  非公開のままです。
- 下記のいずれかの AI クライアント。

## インストール

### Claude（デスクトップアプリまたはウェブ）

1. 左サイドバーの **Customize** を開き、**Plugins** タブへ。
   Claude Cowork の場合は先に **Cowork** タブを開いてください。
2. **Personal plugins** の欄で **+** → **Add marketplace**。
3. **Add from a repository** を選び、次を貼り付けます：
   `https://github.com/lunatalkai/moonloom`
4. 一覧から **Moonloom** を選んで **Install**。

### Claude Code（コマンドライン）

```bash
claude plugin marketplace add lunatalkai/moonloom
claude plugin install moonloom
```

インストール後は Claude Code を一度再起動してください。セッション内では
`/plugin` でも同じ操作ができます。

更新するとき：

```bash
claude plugin update moonloom
```

### ChatGPT Work / Codex

まずコマンドラインでソースを追加します：

```bash
codex plugin marketplace add lunatalkai/moonloom
```

そのあと ChatGPT デスクトップアプリを再起動し、**Plugins Directory** を開いて
このソースを選び、**Moonloom** をインストールしてください。

更新するとき：`codex plugin marketplace upgrade`。

### Cursor

このリポジトリには Cursor 用のプラグイン定義も同梱しています。Git リポジトリから
プラグインを追加する Cursor 側の手順に従ってください。

## 最初のサインイン

Moonloom はオンライン接続で LunaTalk とやり取りします。そのためアシスタントが
最初に LunaTalk のツールを呼ぶとき、ブラウザーが開いてサインインと許可を求めます。
一度許可すれば、あとはそのまま使えます。

- 認可は 8 時間有効で、最長 30 日まで自動的に更新されます。
- ブラウザーに認可完了と表示されたら、AI クライアントへ戻るまでページを閉じずに
  お待ちください。

詳細は [`references/oauth-client-lifecycle.md`](references/oauth-client-lifecycle.md)。

## 動作確認

アシスタントにこう伝えてください：

> Moonloom で私の LunaTalk ロールカードを一覧にして。

自分のカードが返ってくれば設定完了です。

## 次に言えること

Moonloom はコマンド一覧ではありません。ふつうの言葉で伝えて大丈夫です：

> 人を守るために嘘をつく探偵のカードを作って。

> このカード、3ターンで飽きられる。原因を調べて直して。

> このカードを実際にプレイして、プレイヤーがどこで興味を失うか教えて。

> このカードは提出できる状態？

アシスタントが適切な流れを選び、項目を下書きし、技術要件を確認し、費用に同意
すれば実際の会話テストまで行い、まだ足りない点を教えてくれます。

## カードは 2 通りの遊ばれ方をします

プレイヤーは通常どおり会話することも、会話を **Agent モード** に切り替えることも
できます。Agent モードでは、キャラクター自身が返信の前にあなたの書いた素材を
探しに行きます。

これは「世界観設定の項目がどうすれば見つかるか」を変えます。通常はトリガー語が
一致して項目が浮かび上がります。Agent モードではキャラクターが自分で一覧を見て
検索するので、**まず項目名**が目に入り、次に本文の言葉を探します。「場所3」と
いう名前の項目は、そこでは実質的に見えていません。

Moonloom は両方に向けて書き、両方でテストし、そのカードが実際どちらのモードで
確認されたのかを明示します。
[`references/agent-mode-runtime.md`](references/agent-mode-runtime.md) を参照。

## 費用と範囲

- 構想・レビュー・技術検証そのものに追加費用はかかりません（AI クライアント側の
  利用量のみ）。
- 実際の会話テストは LunaTalk 通常のチャット課金で、ポイントを消費します。
  アシスタントは使う前に必ず確認します。Agent モードのテストは実際の使用量に
  応じた課金で、より高くなります。
- Moonloom が編集するのはあなたのアカウントの非公開カードだけで、明確に指示しない
  限り審査に提出することはありません。

## うまくいかないとき

- **LunaTalk のツールが見えない**：インストールや更新のあとはクライアントを再起動
  してください。プラグインは起動時に読み込まれます。
- **ブラウザーは認可完了なのにアシスタントが待ったまま**：ページを閉じず、表示
  されている戻る操作を使ってください。
- **Agent モードが拒否される**：無料モデルでは実行できません。有料モデルを選んで
  ください。対応可否はモデル一覧に表示されます。
- **カードを編集できない**：公開カードは読み取り専用です。まず自分の非公開カード
  として複製してください。

## 同梱されているもの

Moonloom は複数のスキルと共有リファレンスで構成され、アシスタントはその時の作業に
必要なものだけを読み込みます。完全な一覧は
[English README](README.en.md#what-is-included) を参照してください。

- **スキル（`skills/`）**：構想、キャラクターの芯、世界観、開幕、声、インタラ
  クションのループ、状態設計、表示、トークン配分、レンダー確認、実プレイ、反復、
  提出前チェックまで、それぞれ専用のスキルがあります。迷ったときは
  `using-moonloom` が入口です。
- **リファレンス（`references/`）**：カード執筆の枠組み、世界観設定と想起の設計、
  Theme V3／XMLV3 の表示、2 つの実行モードの違い、品質スコアカード、安全と費用の
  境界など、公開されたガイドです。
- **MCP ツール**：カードの作成・修正・検証・プレビュー・実プレイ・提出を実際に行う
  インターフェースで、エンドポイントは `https://api.lunatalk.ai/mcp/card-writer`
  です。Moonloom 独自の権限スコープはなく、サーバー側でアプリと同じログイン識別、
  所有権、クォータ、審査、公開、課金のルールが適用されます。
