# Moonloom Originality Adaptation

Use this reference when an author brings a canon/IP character, fan premise,
another role card, a copied draft, or a recognizable inspiration and wants a
LunaTalk card that can stand as an original work.

Originality adaptation is not a refusal to use inspiration. It turns inspiration
into a new playable engine:

```text
inspiration -> transferable fantasy -> original substitutions -> distance check -> card packet
```

## When to use

Use originality adaptation when:

- the author says "like X", "inspired by X", "based on this card", "make this
  original", "avoid copying", "not canon", "file off the serial numbers", or
  similar
- the draft has exact names, quotes, scenes, outfits, lore terms, factions,
  relationship history, or visual symbols from a recognizable work
- a public card should preserve the emotional fantasy while changing the fiction
- sample calibration flags copy risk that needs a stronger transformation pass

Route away when:

- the author only has a large original material pack: use material distillation
- the task is only public copy packaging: use profile packaging
- the task is only visual prompt originality: use visual identity
- the author explicitly wants a canon/fan card and confirms allowed use; then
  keep only the facts needed for the scene and still avoid brittle trivia

## Transform, Do Not Rename

Do not copy exact names, quotes, scene text, outfits, proper nouns, faction names,
artifact names, route labels, tag strings, or distinctive image compositions from
the inspiration.

Avoid a renamed copy. A draft is still too close if a reader can say:

- "This is the same character with different names."
- "This scene has the same setup, prop, reveal, and emotional beat."
- "The roleDesc and welcome only swap nouns."
- "The voice uses the same catchphrase pattern or quote rhythm."
- "The world keeps the same unique rule with new labels."

## Transferable Fantasy

Keep craft structure, not surface material:

| Keep | Transform |
|---|---|
| relationship asymmetry | new history, leverage, debt, taboo, or secret |
| player fantasy | new player role and first-scene pressure |
| emotional tension | new contradiction, cost, pacing gate, or boundary |
| voice function | new rhythm, vocabulary, tells, and refusal style |
| world function | new rule, location logic, state, and route costs |
| scene mechanic | new place, object, timer, witness, risk, or choice |

The goal is to preserve why the inspiration works while making every fictional
choice new enough to drive a different card.

## Original Substitution Axes

Change at least five of these when adapting recognizable material:

- role identity: job, social position, obligation, or mask
- player role: what the player knows, controls, risks, or can refuse
- relationship history: who owes, betrayed, rescued, hid, or misread what
- pressure source: timer, ritual, debt, public event, route lock, illness,
  invitation, inspection, or missing object
- setting rule: what changes choices, not only the setting name
- symbolic object: what the player can touch, keep, break, return, or hide
- voice strategy: sentence rhythm, address terms, tells, avoided phrasing
- visual motifs: silhouette, color, object, setting pressure, framing
- state labels: trust, debt, heat, clue, favor, suspicion, route, habit, risk
- opening proof: place, role action, player implication, and second-turn move

## Distance Check

Before handoff, ask:

- Could the card be pitched without naming the inspiration?
- Does the player role differ in what the player can decide or withhold?
- Does the first scene use a different place, object, timer, and pressure?
- Does the role's voice have new rhythm and avoidance rules?
- Does the world or relationship state change through different labels?
- Would replacing the names reveal that it is still the same scene?

If the answer shows renamed-copy risk, repair the substitutions before writing
fields.

## Handoff

- Use premise workshop if the author needs several original directions.
- Use character core when the adapted role still feels like a trope shell.
- Use relationship, world, scenario, daily-life, play, generator, or ensemble
  skills when the adapted engine needs a narrow packet.
- Use visual identity when the adapted image direction is still too close.
- Use card author only after the originality adaptation packet passes the
  distance check.
